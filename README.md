# Chatbot pédagogique Maroc

## 🎯 Description
Ce projet est un chatbot pédagogique intelligent destiné aux enseignants d’informatique du cycle collégial au Maroc.

Il utilise une architecture RAG (Retrieval-Augmented Generation) basée sur des documents officiels marocains afin de fournir des réponses pédagogiques et didactiques fiables.

---

## 🧠 Objectif
Aider les enseignants à :
- Comprendre les concepts pédagogiques
- Préparer leurs cours
- Identifier les compétences visées
- Appliquer les orientations officielles

---

## 📚 Documents utilisés
- Orientations pédagogiques d’informatique
- Programme officiel du collège
- Livre blanc (partie pédagogique)
- Mيثاق وطني للتربية والتكوين
- Loi-cadre 51.17

---

## ⚙️ Technologie
- Dify AI
- GPT (LLM)
- RAG (Retrieval Augmented Generation)

---

## 💬 Fonctionnalités
- Réponse aux questions pédagogiques
- Aide didactique pour enseignants
- Explication des notions du programme marocain
